# PIXEL

Сайт компьютерного клуба в Астане. На сайте можно посмотреть залы, цены и игры, выбрать время визита и управлять записями в личном кабинете.

## Локальный запуск

Нужны Python 3.10+ и браузер с JavaScript.

```sh
python booking_server.py --port 8879
```

Откройте [сайт](http://127.0.0.1:8879/). Бронь с именем, телефоном и параметрами визита отправляется администратору в Telegram. Войдите в аккаунт, чтобы изменять дату, время и ПК или отменять запись. Гостевая бронь привязывается к аккаунту при входе на том же устройстве. Изменения и отмена также отправляются в Telegram. Онлайн-оплата не подключена.

Для доступа с телефона в этой сети запускайте `start-lan.cmd` и открывайте [сайт в локальной сети](http://192.168.31.40:8880/). Этот запуск включает Telegram и сохраняет вход и остальные функции локального сервера:

```sh
python booking_server.py --local --telegram --host 192.168.31.40 --port 8880
```

## Настройки

- Настройки Telegram хранятся в приватном `env/.env`: `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `PUBLIC_ORIGIN`. Файл исключён из Git. Отправка включена при обычном запуске или с сочетанием `--local --telegram`.
- Для входа через Google настройте Firebase, добавьте локально `FIREBASE_API_KEY`, `FIREBASE_AUTH_DOMAIN`, `FIREBASE_PROJECT_ID` и `FIREBASE_APP_ID`, установите `requirements-auth.txt` через `pip` и задайте `GOOGLE_APPLICATION_CREDENTIALS`.
- Страницы и ресурсы находятся в `demofinal/`. Сервер работает на Python, локальные данные хранятся в SQLite в каталоге `var/`.
