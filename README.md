# PIXEL

Сайт компьютерного клуба в Астане. На сайте можно посмотреть залы, цены и игры, выбрать время визита и управлять записями в личном кабинете.

## Локальный запуск

Нужны Python 3.10+ и браузер с JavaScript.

```sh
python booking_server.py --local --port 8879
```

Откройте [сайт](http://127.0.0.1:8879/). В «Плане визита» можно оформить демо-бронь без оплаты, оплатить визит демо-картой или с демо-баланса. В профиле доступны пополнение и отмена предстоящих визитов. Демо-операции не списывают реальные деньги.

## Настройки

- Для отправки заявок в Telegram скопируйте `.env.example` в `env/.env`, заполните `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID` и `PUBLIC_ORIGIN`. Запускайте сервер без `--local`.
- Для входа через Google настройте Firebase, заполните `FIREBASE_*` из шаблона, установите `requirements-auth.txt` через `pip` и задайте `GOOGLE_APPLICATION_CREDENTIALS`.
- Страницы и ресурсы находятся в `demofinal/`. Сервер работает на Python, локальные данные хранятся в SQLite в каталоге `var/`.
